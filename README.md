<h1>Plankton</h1> 
<h4>Archive / Level Editor for GoodEngine games by Heavy Iron Studios.</h4>

Editor for file type <b>.ho</b>

<h2>Supported Games</h2>
<p>
- Ratatouille<br>
- Wall-E<br>
- Up<br>
- Truth or Square (Xbox, Wii)<br>
- UFC Personal Trainer<br>
- Harley Pasternak's Hollywood Workout<br>
- Family Guy Back to the Multiverse<br>
</p>

3D Editor currently only supports Spongebob's Truth or Square Wii.

<h2>Controls</h2>
<h3>Camera</h3>
Pan: Middle Mouse Button / IJKL<br>
Zoom: Mouse Wheel<br>
Moving around: Shift + Middle Mouse Button / WASD EQ<br>

<h3>Editing</h3>
<p>
Select: Left Mouse Button (Click or Box Select), Hold shift to keep old selection<br>
Grab: G<br>
Rotate: R<br>
Scale: B<br>
Axis selection: XYZ, Hold shift to exclude an axis<br>
Duplicate Object: Shift + D<br>
Focus on Object: F<br>
</p>

For customization, go to Edit -> Edit Preferences


<h2>Dependencies</h2>
- OpenTK <br>
- Assimp <br>
- CSHO (https://github.com/HiMemX/CSHO)<br>
- libWiiSharp <br>
- HexBox (https://www.nuget.org/packages/Be.Windows.Forms.HexBox) <br>
